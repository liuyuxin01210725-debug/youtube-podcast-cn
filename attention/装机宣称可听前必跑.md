# 装机 / 宣称可听前必跑

声间往手机上装、或对别人说这版可以听之前，先跑：

```bash
make shengjian-before-claim-ready
```

没有 swiftc（Mac 上一般是 Xcode 的 `xcrun swiftc`）时这一目标会失败，不能跳过。仓库里没有手机 UI 自动化，这一步用单测和字符串探针代替手点。

通过才算这三件事还在：

1. **继续播放。** 短播（不到 5 秒和超过 5 秒）后回到资料库，唯一那张卡是刚听的那集。左滑仍能拿掉。听这段不写 ListenMark。在听芯片仍是满 5 秒才算。
2. **听后感。** `ListenNoteSection` 还在播放页里，并且排在提炼区块前面。
3. **mockgate。** 没有 Live key 时不把占位 mock 写成 ready；状态不能标成「已提炼」。

本机如果已经编出 `PrivateListen.app` 或 dylib，脚本会再用 `strings` 核对「继续播放」「听后感」「mock_not_official」。没有编出来的包时，源码探针加上面的单测就是门禁。
