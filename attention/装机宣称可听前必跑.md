# 装机 / 宣称可听前必跑

声间往手机上装、或对别人说这版可以听之前，先跑：

```bash
make shengjian-before-claim-ready TIP='branch@完整SHA'
```

也可传 `SHA=`。入口先读 `dist/CURRENT-iphoneos.sha.txt`，指定外部记录可设 `SHENGJIAN_BUILD_RECORD`。记录开头须为 `branch@SHA`，同目录 `CURRENT-iphoneos` 必须指向名称含该构建 SHA 的包。短 SHA 须在本地 Git 对象中唯一。缺少 tip、记录或包，或远端记录分支未公布同一完整 SHA，都会失败。

入口还要求 swiftc（Mac 上一般是 Xcode 的 `xcrun swiftc`）。真机交互单独验收。

通过才算这三件事还在：

1. **继续播放。** 短播（不到 5 秒和超过 5 秒）后回到资料库，唯一那张卡是刚听的那集。左滑仍能拿掉。听这段不写 ListenMark。在听芯片仍是满 5 秒才算。
2. **听后感。** `ListenNoteSection` 还在播放页里，并且排在提炼区块前面。
3. **mockgate。** 没有 Live key 时不把占位 mock 写成 ready；状态不能标成「已提炼」。

二进制探针只扫描绑定的 CURRENT 包，核对「继续播放」「听后感」「mock_not_official」。
