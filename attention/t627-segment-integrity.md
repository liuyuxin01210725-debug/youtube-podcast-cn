# 普通发布逐段完整性

2026-11-23（Asia/Taipei）。普通发布以逐段完整性替换整集时长对字数。独立诊断的时长对字数保留。续用 ffprobe、完整解码、静音、削波、响度及抽检 MP3 的原规则。

必须有与音源、文稿和成片哈希绑定的 Edge 逐段证据。可念段按文稿顺序各有成功请求身份、匹配清洗后输入 SHA-256 和正帧长。重复的同槽同文本须分别有证据，旧格式无法区分的重复请求拒绝。纯标点或清洗后只剩舞台提示的段遵守 24 kHz、2,880 帧静音，无 SDK 请求；新渲染同时核对静音片段 PCM。最终单声道解码得到的实际样本数须严格等于逐段 PCM 帧和。缺收据待核，声明了逐段证据但数据缺损或不符时硬拦。历史没有记录的身份仍留缺。

逐段闸 `CLEAR` 只表示已通过上述完整性核验。段内静默截断仍可能通过，继续保留原质量闸和人耳实听。自动预检的 `publish_ready`、`audio_quality_pass` 恒为 false。`CLEAR` 不代表已听或音质 PASS。本轮不发布或部署。
