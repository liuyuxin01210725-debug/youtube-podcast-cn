# Edge 渲染证据

普通发布政策见 [t627 逐段完整性](t627-segment-integrity.md)。下文末段记录 t625 当时的门禁。

2026-11-23（Asia/Taipei）。有音源锁的整期 Edge 渲染在既有 `render-identity.json` 时轴里附带请求证据。音色来自当前后端对声槽的解析，落盘的声名、速度和 SSML 根语言来自成功请求使用的 SDK 配置。另记音色地区及 SDK 版本。当前固定依赖默认速度为 `+0%`，播放器音色、清洗和合成参数沿用原行为。

观测口径为应用送入 `edge_tts.Communicate` 的清洗后字符串。每个 Unicode 码点计一，含中英、数字、保留的标点、空格和换行，不做发音权重。记录码点数及 UTF-8 SHA-256。广告不进时轴，只剩标点等无可朗读内容的段沿用 0.12 秒静音，计零。该计数与音频时长或听感分开。

新缓存只复用与 WAV 哈希、缓存键、声槽、文本摘要相符的请求证据。旧缓存可继续复用音频，缺证的时轴项为 `null`，历史音轨不回填当前配置。带新版证据标记的成品在包校验时拒绝缺失或不匹配的时轴证据。这些哈希提供本地一致性核查，独立语速校准尚未建立。

普通发布仍不加载生产语速基线或测试基线，缺校准为 `REVIEW`。沿用原 25% 门禁及其预检、抽检规则。顾问自定阈值未采纳。本轮只做离线准备，生产制作未恢复，未生成生产基线。
