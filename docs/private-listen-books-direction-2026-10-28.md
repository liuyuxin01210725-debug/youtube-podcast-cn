# 私人听 · 书听方向（2026-10-28，讨论稿，未开做）

HO鑫：私人听 ≠ 仅英文播客转写；要多种收听——英文书（无中文版则译+读）、中文书（搜版本后听）；长书不能整本一条从头播；借鉴微信读书等。

## 产品原则（先定）

1. **同一 App / 同一私人库**，内容类型分：播客成片 / 书（再分译制英书、中文朗读）。
2. **一本 ≠ 一条超长 episode**。最小听单元 = **章（或固定时长块，如 15–20 分钟）**，带目录、已听进度、续听书签。
3. **进度是书的一等公民**（不像播客推荐信号）：章级 + 句/段级书签；换设备靠现有 iCloud 库同步。
4. **版权**：只朗读用户有权使用的文本（自有 epub/pdf、已购、公有领域）；不做盗版源聚合。找「版本」= 帮用户定位合法来源或他自己丢进来的文件。
5. **闸门对齐播客**：英书译制仍可「点头才开长译」；中文书若只需 TTS，成本低可更轻确认。

## 借鉴（机制，不抄壳）

| 来源 | 可借 |
|---|---|
| 微信读书 | 章目录、听书进度条、定时关闭、速度、边听边进度同步；「从上次离开的地方继续」 |
| Apple Books / 得到听书 | 章列表为播放列表；休眠定时 |
| Audible | 书签 + 剪报（日后可接知识网，非 P0） |
| 现有私人听 | 锁屏 Now Playing、iCloud 库、分享入队 |

不借：社交书评噪声、强制推荐书单商城。

## 建议分阶段

**P0 形态（想清楚再开做）**
- 入库：用户丢 epub/txt/pdf（中文）或「译这本英文」（需合法文本）。
- 切章：TOC 优先；无 TOC 则按标题/字数切 15–20 分钟块。
- 播放：App 里书对象 = 多轨 playlist；记住章+偏移。
- 英译：复用 DeepSeek 译 + Edge TTS；**单声道朗读者**（书默认 1 音色，避免播客那套多人声纹）。

**P1**
- 合法书源检索助手（只给购买/图书馆/公有领域链接，不抓盗版）。
- 章末极短「刚才讲了什么」可选。
- 与知识网打通书签（仍待「开做」知识网）。

## 与播客流水线的差异（避免再踩坑）

- 书：**禁止跑多人声纹**；固定 `narrator` 一槽。
- 书：进度 UI 必须先于「能不能整本合成」；可按章懒合成（听到哪生成到哪），降低首听等待。
- 播客硬闸（人数=音色数）与书听分轨，互不污染。
