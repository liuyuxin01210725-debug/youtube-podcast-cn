## 4. 开干前必补（恰好 ≤5 条硬规格 · 可验收）

以下五条已写入权威规格 **§13**；**未写入 / 未验收前，禁止动 Extractor / 卡片 / 收藏手势实现，也禁止把 PR#19 算作抽取交付。**

1. **时间参照系 + span 可定位**  
   `t_start`/`t_end` = 手机正在播的 **`output.mp3` 轴**（口播广告已掐、中文合成按拼接累加后的偏移）；源字幕 `start_ms` 只留 Mac 侧映射。每条 `span` 必须在当前 `transcript_hash` 对应文本中可定位（精确或规格允许的归一化）；定位失败 → **拒收**该条（不得改记源片时间；不得无 span 出卡）。

2. **extract 独立持久化 + 跳回原句不写 ListenMark**  
   Packet 与每条确认/丢弃/动作态存在与 episode 关联的独立 **`extract.json`（或等价）**；再次发布 `episode.json`/`output.mp3` 时 **合并保留**，禁止整文件覆盖清空。Markdown 从该状态导出。「跳回原句」**只移动播放头**；`ListenMark` / 续听书签仍只由播放进度写入。

3. **light 不进待确认 + 详情默认只展待确认 + 列表徽标密度上限**  
   听完 light 只留一行 `summary_line` + 折叠名录；**不生成须逐条确认的卡片**，不占「N 条待确认」。待确认只来自 deep/manual 必抽槽。详情提炼区：**默认只展开待确认**；低置信/已确认按槽折叠。列表同时展示提炼态的行有 **密度上限**（超额降级为统一弱点提示，禁止每行长文案角标）。

4. **取消收藏撤未完成 deep + 确认废墟弱提醒 + 动作可找回**  
   任务仍在 `queued`（及未完成的 running，按实现可停）时 **取消收藏/星标 = 撤销任务**，不扣满额 deep；已 `ready` 的 Packet 不因取消星标自动删除。Packet ready 后长期 **0 确认** → 徽标降级或单集弱提醒一次（非 Inbox，不破 Q2）。试用清单 / 待读 / 讨论 / 候选信源须有 **库内可找回最小态**（状态芯片或详情外过滤均可；**禁新 Tab**）。

5. **健康「仅记录」+ 投资不主视觉看多看空**  
   `health` Method 主按钮文案为 **「仅记录」**（不用「待实践」）；免责短句（非诊断、非处方）**贴在该按钮旁**，不放页脚。剂量/频率/动作对不齐 span 或置信 &lt;0.5 → **丢弃不展示**。`biz_invest` 卡片 **主视觉不出现「看多/看空」**；Org 保持观察候选。两条路径均不做跟买、跟练、涨跌提醒。

## 7. 最狠 3 洞（转述用）

1. **时间轴错位（Cursor）**：用户听的是掐广告后的中文成片轴；若按源片时间戳 seek，跳不回原句，强制 span 反而给幻觉发证件。  
2. **假交付前置（Cursor）+ 确认废墟（本机）**：设计页写着「收藏=深抽」，库里没有状态机；就算抽出一堆待确认卡，用户从不点确认 → 结构化二次假拥有。  
3. **light 打穿 Q2 × 状态被发布清空**：听完 light 若进待确认，Inbox 被禁止出现之前确认已爆；确认态若写进会被再次发布覆盖的 `episode.json`，第一知识库一夜归零。
